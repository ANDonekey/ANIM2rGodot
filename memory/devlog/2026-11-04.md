## 本轮钉死的语义（均为实测/汇编级）

1. **实参引擎序**：函数与 syscall 的 arg0 = 最后压栈值（exe 句柄自值栈顶向下读取，FUN_00420F80 page_create 汇编 + yazlib 淡入 worker 实参用途双证）。VM `_push_frame` 的 frame.args 与 syscall 分发均已反转；此前 page_create 宽高互换、worker 把 sprite id 当 wait 时长皆源于此。
2. **bsel.5 = 帧析构函数**（FUN_00413640 只登记 state+0x24；mjil 标注 `@destructor`）：帧 ret 时先跑析构（帧上下文保留），thread_end 杀线程时先跑顶帧析构，点击跳过 = 中断等待直跑析构。pic 的 $1635363c 实为 thread_begin 返回的 tid，等待环据此轮询、析构置 0——旧的「跳转模型」只能覆盖 DO_TRANSITION 一例，析构模型统一覆盖 pic/yazlib/transit 三类。
3. **等待族**：wait(≤0) = 帧同步等待（一帧）；0xFF75CD29 是 timer_sync(state, 间隔) → 新 state（落后超 4 个间隔时重同步到当前时刻，防慢帧追赶螺旋）；timer/get_current_time$ 返回 Stage 时钟；wait 的重入键由处理函数自有（tick 只唤醒不删键——曾因 tick 删键导致 wait 永久重装死锁）。
4. **areaevent**：set(id,x,y,xl,yl,on,off,click,flags) 引擎序；回调实参 = 该区域自身的 (id,x,y,xl,yl)；area 的点击锁存独立于 mk_unwait（曾被脚本的 mk_unwait 吞掉）；areaevent_check 由脚本循环调用分发。
5. **event_hook/do_event**：钩子按名登记（实参序：名、函数哈希），do_event 以事件实参逐个 spawn 处理线程。DO_TRANSITION 是引擎原生事件，不走脚本钩子：工作线程在 do_event_single 上挂起（时长取其实参中的毫秒值），呈现为 front 向目标页淡入，完成时整页接管 front；点击可提前结束。
6. sprite 坐标 = 区域左上角（标题 logo/菜单整页图 (0,0) 放置与原版逐像素吻合证）；sprite_paste(dst_page, src_page) 按 sprite 位置/alfa/掩码把 src 页 sprite 光栅化进 dst 页（FUN_0044C5E0 遍历 sprite 链表匹配页对）。
