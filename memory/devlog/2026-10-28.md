## Web 无声 bug 修复（2026-10-29 00:xx，用户报告"任何声音都没有"）

- 现象：公网 Web 版全程无声（BGM/语音皆无），桌面端代码路径无改动。
- 排查（探针驱动，结论按实测）：worklet 文件 MIME/状态码正常；AudioContext 点击后 running；游戏源文件与 bundle span 字节一致、BGM 解码 mean -14.8 dB 真实音频。关键分流：Godot 4.3+ Web 默认 **Sample 播放模式**（AudioBufferSourceNode 直放，不经混音器/worklet）——早期量 worklet chunk 全零是量错通路（该模式下本就为零），最小工程同模式下 source→destination 正常（0.366→0.518)。本游戏公网实测：source 峰值 0.4~0.8（语音/BGM 都在播）、**destination 峰值恒 0**，信号死在 source 与 destination 之间的 Sample 图里（Master/Voice 两路皆死；与论坛"运行时建总线在 Web 出问题"的报告方向一致，但最小工程未复现，未再深挖具体环节）。
- 修法：`AudioDirector.setup()` 中 web 平台把三路播放器 `playback_type` 设为 1（Stream）。注意 Godot 4.7.2 未向 GDScript 暴露 PLAYBACK_TYPE_* 常量（写常量名会 Parse Error 且导出不报错、运行时才炸——须开机冒烟查控制台）。Stream 模式下总线峰值表恢复，口型同步（voice_level 读 Voice 总线峰值）在 Web 也生效。
- 验证：本地 dst 峰值 0.22~0.82、Voice 总线峰值 -1.7 dB；推送 4af4361 + R2 重新部署（pck 16,595,928 B）后公网复测 dst 0.22~0.39、主总线 -20.7 dB，确认有声。
- 附带：autoplay harness 新增 `window.__animAudio` 实时音频探针（AudioDirector.debug_state：播放状态/总线峰值/增益），保留作回归工具。标题画面无 BGM 仍是旧缺口（曲目未定）。
