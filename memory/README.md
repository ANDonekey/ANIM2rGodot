# memory/

本项目的**开发记忆**：跨会话保存的持久结论与逐日开发日志，让任何一次新的
开发会话（人或 AI）都能从这里恢复上下文，而不是从零开始。

- `MEMORY.md` — 持久记忆：项目身份、已拍板决策、已攻破格式的结论性摘要、
  实测数字、踩过的坑、未决事项。只写经得起时间的内容，保持精简。
- `devlog/YYYY-MM-DD.md` — 逐日日志：当天做了什么、验证了什么、留下了什么问题。

维护约定：

- 每个开发里程碑同步更新这里，与代码同仓库、同提交节奏；
- 只记本项目相关内容；密钥、令牌等敏感值不入库（结论可记，值不写）；
- 结论标注证据级别：实测 / 文档 / 推断，被证伪的当场修正并留痕。
