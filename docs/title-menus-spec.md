2048×2048 画布、实际画面在子矩形内；我们的加载器已能解 .gax，运行时直读）。

| CG/回想 | 同上 | `pCgButton.gax` / `pMemoryButton.gax` |
| 音乐 | 同上 | `pMusicButton.gax` |
| 立绘展台 | 同上 | `spEmoteRoomButton.gax` |
| Backlog | 游戏内 | `spBackLogButton.gax`、`spMessageWindowButton.gax` |
| FLOW | `spFlowChartBase.gax`（**整张流程图预渲染成一幅图**，含图例/路线行） | `spFlowChartButton.gax`、`pFlowChartBase.gax`（另一变体，差异待核）、`spFlowhelp.gax`（游戏内 FLOW 帮助页） |

因此复刻路线定版：**素材直读 + 引擎只负责状态叠加与交互**（悬停切图、
节点着色、滑杆位置、动态数字/文本），不重绘画面。按钮格切分坐标与各图的
实际子矩形在实现期从像素实测（我们的 GAX 解码给出子矩形参数）。

FLOW 的数据面：底图是死的，活的是「节点矩形 + 节点→脚本位置 + 通过/当前状态」。
数据来源候选（实现期按序核）：① `kabe2_define.dat` 中 em 表以外的未解段
（长期 backlog 项）；② `voice/kabe2_system.dat`（521 KB，疑似系统/状态数据，
包内另附一份于全CG存档目录）；③ sce 流内标记。官方口径旁证：Shiravune/ANN
官方公告把本作卖点写为 "flowchart UI with branching choices and shifting
viewpoints"（双视点分支流程图），与实机分行（浩輔視点/千夏視点）一致；
游戏内帮助以 `spFlowhelp.gax` 为准（日方官网产品页本轮未检索到）。

## 4. VOLUME（实测）

- 左列 7 条通道滑杆（MIN–MAX 带刻度），各带「テスト再生」与「再生する」开关
  （マスター无测试按钮）：マスター / BGM / 効果音 / BGV /
  BGV（台詞再生中）/ 環境音 / 環境音（Hシーン）。
  默认：マスター 100%、BGM・効果音 约 62%、其余约 50%。
  BGV = 背景人声（环境音声）；「台詞再生中」是台词播放时 BGV 的压低量（ducking）。
- 右侧「キャラクターボイス」：角色头像列表（实测 2 人：千夏、秀鹰），选中后大卡片
  （立绘 + 角色名 + CV 名）+ テスト再生 + 再生する + 个人音量滑杆（千夏默认约 85%）。
  → 每角色独立音量/静音。角色全名单实现期核对（**推断**为全部有语音角色）。
- 「VOLUMEの初期化」复位；底部与 CONFIG 互跳。
- 对应现有模块：播放器音频总线已有 master/bgm/voice/se 雏形。需扩：BGV/環境音
  分类（数据侧要确认 BGV 与環境音在 sce 里如何标记——opcode 层面区分，**推断**
  是 BGM 通道的子类型/独立命令，实现期查）、ducking、按角色音量（语音文件名
  带角色前缀，可按前缀路由）。

## 6. FLOW（フローチャート，实测）

- 方格纸底，按「视点 × 路线」分行（实测行：浩輔視点 / 千夏視点 /
  浩輔視点・千夏ルート / 千夏視点・千夏ルート / 浩輔視点・文子ルート…）。
- 节点三型：方=通常/END、菱形=選択分岐、圆=自動分岐；分支组带编号跳转标（1へ/2へ/3へ）。
- 颜色图例：現在位置（红）/ フォーカス（绿）/ 通過位置（黄）/ 選択分岐（品红）/
  自動分岐（蓝）/ END（紫）/ 灰色通過点 = 不可直接跳转（※注记明示）。
- 左下信息框：聚焦节点的场景首行文本。右下：＋/全体図/－（缩放）、
  「FLOWを初期化」（清通过记录）、「前の画面へ戻る」。
- 点已通过节点 = 跳入该点继续游戏（引擎的快照跳转）。
- 对应现有模块：我们有全脚本 CF 图（标号/分支/选项全量）+ 快照存档 +
  已通过记录（回想解锁集合）。原版节点布局是人工编排的；复刻方案二选一：
  (a) 数据驱动自动布局（按 sce 标号段生成行列），(b) 人工标注布局数据。
  节点粒度（多少事件一个节点）实现期对原版节点数与脚本标号对照核定。

### 3.1 实测补充（2026-10-28 晚，instabox 原版存档实拍）

- SAVE 画面与 LOAD 同构（底图 spSave 为偏蓝纸色、烘焙在素材里）；游戏内打开时底部三按钮：前の画面に戻る / TITLE画面へ / 模式切换（LOAD画面へ⇄SAVE画面へ）；标题进入 LOAD 时只有前の画面に戻る。

- 有档槽位：编号右侧两行小字日期 `yyyy/MM/dd` / `hh:mm:ss`——分隔符 / : 是槽位底图烘焙的，引擎只贴数字组；最新存档带 NEW 徽章；悬停槽位时顶部 SAVE No. 显示该槽编号，预览框整幅显示缩略图（16:9 铺满内框）。
- 保存时闪示「サムネイル画像をセーブ中です」横幅（spLoadButton 内素材）。
- SAVE No. 输入框可键入跳槽（本轮未复刻，字段仅显示悬停编号）。
